Flight Pricing API

Technical reference for accessing real-time, agency-specific flight prices and seat availability from the Albania Sky inventory system.
Issued to: TRAVEL AGENCY 771
albaniasky.com · API v1 · June 2026

01 Overview

The Albania Sky Partner API gives your system real-time, read-only access to all available flights and their agency-specific prices. Every price returned is the exact price your agency pays — with any agreed discount already applied.

What this API provides Live flight inventory (airline, route, dates, times) · Agency-adjusted adult / child / infant prices · Exact available seat count · Checked baggage prices · Automatic price updates when Albania Sky changes a price or your discount terms.

Base URL

https://albaniasky.com/api

All requests go to this base URL. The API communicates exclusively over HTTPS. All responses are JSON (Content-Type: application/json).

03 Endpoints

3.1 List Available Flights

GET/v1/agent/flights

Returns all currently available flights with your agency-specific prices applied. Results are ordered by departure date and time. Only flights with at least one available seat are returned.

Query Parameters (all optional)

ParameterTypeExampleDescription
fromstringTIAFilter by origin IATA airport code (case-insensitive).
tostringLGWFilter by destination IATA airport code (case-insensitive).
datestring2026-07-20Filter by exact departure date (YYYY-MM-DD format).

Example Request

# All available flights
GET https://albaniasky.com/api/v1/agent/flights
X-API-Key: ask_e882eecf3cfc9d5ac605501315b9f46795337e08c27a50e23f22a1bf15e46db7

# Flights from Tirana to London on 20 July 2026
GET https://albaniasky.com/api/v1/agent/flights?from=TIA&to=LGW&date=2026-07-20
X-API-Key: ask_e882eecf3cfc9d5ac605501315b9f46795337e08c27a50e23f22a1bf15e46db7

3.2 Get Single Flight

GET/v1/agent/flights/:id

Returns a single flight by its numeric ID with your agency-specific price applied.

Example Request

GET https://albaniasky.com/api/v1/agent/flights/5001
X-API-Key: ask_e882eecf3cfc9d5ac605501315b9f46795337e08c27a50e23f22a1bf15e46db7

{
  "id": 5001,
  "airline": "WIZZ AIR",
  "flight_number": "W6 4764",

  "from_city": "Tirana",

  "arrival_time": "09:00",
  "currency": "EUR",

  "price_child": 60.00,           // child age 2–11
  "price_infant": 20.00,          // infant under 2

  "available_seats": 12,          // exact number of seats still available

  "updated_at": "2026-07-01T07:00:00.000Z"

4.3 Field reference

FieldTypeDescription
price_adultnumberFinal agency price for one adult — your discount already deducted.
price_childnumberFinal agency price for one child (ages 2–11).
price_infantnumberFinal agency price for one infant (under 2).
available_seatsintegerExact number of unsold seats at the time of the request.

05 Error Responses

All errors return a JSON body with an error field.

HTTP StatusMeaningExample body
401 Unauthorized API key missing or invalid. {"error":"Invalid API key"}
403 Forbidden Agency account is inactive. {"error":"Agency account is not active"}
404 Not Found Flight ID does not exist or is no longer available. {"error":"Flight not found"}
503 Service Unavailable Temporary server issue — retry after a few seconds. {"error":"..."}

06 Pricing & Discount Notes

  • Prices are final agency prices. The values in price_adult, price_child, and price_infant already reflect any discount agreed with Albania Sky. You do not need to apply any further calculation.
  • Prices update automatically. Whenever Albania Sky changes a base price or adjusts your agency's discount terms, the next API call will return the new values with no integration work required on your side.
  • Currency is always EUR.
  • Seat count is real-time. available_seats reflects the exact unsold seat count at the moment of the request. Seats sold through any channel reduce this count immediately.
  • Only open flights are returned. Flights that are sold out, closed, or past their departure date are excluded automatically.

07 Quick-start Code Examples

Python

import requests

API_KEY = "REPLACE_WITH_YOUR_VALUE"
BASE = "https://albaniasky.com/api"

r = requests.get(
    f"{BASE}/v1/agent/flights",
    params={"from": "TIA", "to": "LGW",
            "date": "2026-07-20"},
    headers={"X-API-Key": API_KEY}
)
flights = r.json()["flights"]
print(f"{len(flights)} flights found")

JavaScript / Node.js

const API_KEY = "REPLACE_WITH_YOUR_VALUE";
const BASE = "https://albaniasky.com/api";

const res = await fetch(
  `${BASE}/v1/agent/flights?from=TIA&to=LGW`,
  { headers: { "X-API-Key": API_KEY } }
);
const { flights } = await res.json();
console.log(`${flights.length} flights`);

curl
